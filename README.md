# Sales Data Analysis using SQL

## Overview 
This project analyzes sales data using SQL to extract insights such as revenue, customer spending, and product performance.

## Tools Used
- MySQL

## Key Analysis
- Total Sales Revenue
- Top Customers by Spending
- Best-Selling product
- Monthly Sales Trend
- Revenue by Region
- Average Order Value
- Inactive Customers

## Project Files
- schema_and_data.sql -> Table creation and sample data
- mysql_sales_project.sql -> SQL queries used for analysis
